# Campus Lost and Found App

A web-based campus lost-and-found prototype for Taylor's University Lakeside Campus.

The prototype supports four functional roles without account registration:

- **Finder** — reports a found item and confirms its handover.
- **Item Owner** — searches a timed campus route and manages lost notices or urgent requests.
- **Volunteer Helper** — selects a campus location and receives relevant nearby requests.
- **Visitor** — browses public lost notices.

## Main functions

1. Found-item reporting and handover confirmation.
2. Rule-based route matching using campus locations and visit time intervals.
3. Public lost-notice publication and owner-controlled management.
4. Urgent search requests that remain active for up to 30 minutes.
