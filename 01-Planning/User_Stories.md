# User Stories

| ID | Role | User story | Acceptance summary |
| --- | --- | --- | --- |
| US-01 | Finder | As a finder, I want to report an item so that its owner can locate and collect it. | A valid report becomes Available and shows its collection point. |
| US-02 | Finder | As a finder, I want to confirm handover so that returned items no longer appear in searches. | The originating browser can mark the report Claimed. |
| US-03 | Item Owner | As an owner, I want to search using visited places and times so that I can identify possible matches. | Valid visits return ranked available reports with reasons and pickup locations. |
| US-04 | Item Owner | As an owner, I want to publish and manage a lost notice so that other students can help. | An Open notice is public; the owner can edit or resolve it. |
| US-05 | Item Owner | As an owner, I want to send an urgent request so that nearby students can check the location. | The request is active for up to 30 minutes and can be closed early. |
| US-06 | Volunteer Helper | As a volunteer, I want to receive requests near my selected location so that I can help effectively. | Opting in shows active requests for the same area and refreshes automatically. |
| US-07 | Visitor | As a visitor, I want to browse open lost notices without registering. | The public board displays Open notices without sign-in. |
